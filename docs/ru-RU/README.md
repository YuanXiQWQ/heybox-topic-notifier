Добавьте тему Heybox в настройках, выберите ключевые слова, регулярные выражения или фильтр ИИ и включите периодическую проверку. Найденные публикации можно перемещать из рабочей области в историю и обратно.

Для регистрации нужен код приглашения. Уведомления приложения включаются отдельно на каждом устройстве и работают вместе с почтой или вебхуком. Изменения без подключения синхронизируются при восстановлении связи. Язык и тёмная тема по умолчанию берутся из настроек устройства.

## Возможности

- Панель управления: просмотр состояния опроса, общего числа совпадений, последнего совпадения и ожидающих
  совпадений, а также ручной запуск проверки
- Страница настроек: настройка ID тем, состояния включения, заметок, единицы интервала опроса, лимита
  публикаций, режима сортировки, языка интерфейса, тёмного режима и цвета темы
- Настройки учётной записи: регистрация, вход, выход, обновление имени пользователя и обновление пароля;
  данные учётных записей изолированы по ID пользователя
- Правила ключевых слов: поддержка общих правил, правил для отдельных тем, мест совпадения, учёта регистра
  и регулярных выражений
- Настройки → Настройки уведомлений → Тестовое уведомление
- Каналы уведомлений: пользовательский Webhook, ServerChan, PushPlus, WxPusher, email API и SMTP
- Ретрансляция уведомлений: необязательный relay на Cloudflare Worker для PushPlus, WxPusher и ServerChan

## Локальная разработка

```sh
deno task dev
```

[localhost:8000](http://localhost:8000) · [`.env.example`](../../.env.example) · `deno task check`

## Развёртывание

Служба Deno работает в Oracle Cloud, а Caddy обслуживает HTTPS. Учётные записи, сеансы и результаты хранятся в Turso. GitHub Actions собирает установочные пакеты Windows и Android по тегам выпусков.

[Установка на свой сервер](./deployment.md) · [Cloudflare Worker](./worker.md)
